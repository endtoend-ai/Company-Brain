# 蓝鲸科技公司概况

## 公司基本信息

蓝鲸科技成立于2020年，总部位于浙江省杭州市。公司由周明轩创立，周明轩担任公司创始人兼首席执行官（CEO）。蓝鲸科技聚焦于智能客服和企业对话式AI赛道，以旗舰产品"鲸智"为核心，致力于帮助企业构建高效、智能的客户服务与内部知识交互能力。截至2024年，公司员工规模约为150人。

## 创始人周明轩与创业背景

周明轩在创立蓝鲸科技之前，长期深耕人机交互和自然语言处理领域。他对企业客服场景有着深刻的理解与研究，认为传统客服模式普遍面临三大痛点：人力成本居高不下、服务响应速度难以满足客户期望、以及知识沉淀分散导致客服人员难以快速调取准确信息。

2020年，周明轩在杭州创立蓝鲸科技，选择杭州这一数字经济高地作为总部，既能够充分利用当地丰富的技术人才资源，又能够借助杭州新零售、电商生态对智能客服场景需求的天然驱动力，快速积累商业客户和真实场景数据。蓝鲸科技成立之初便确立了以智能客服平台为核心产品方向，以意图识别和多轮对话技术为核心壁垒的技术路线。

## 旗舰产品：鲸智

鲸智是蓝鲸科技的旗舰智能客服与对话平台，面向企业提供覆盖客服全链路的一体化解决方案。产品定位强调"懂业务、能学习、会协同"，即平台能够理解企业具体业务场景、持续从对话数据中学习优化，同时支持人机协同工作模式。

鲸智在功能架构层面划分为四大核心模块：

第一，意图识别模块。意图识别是鲸智的底层核心能力。该模块基于大规模预训练语言模型，结合企业私有语料持续微调，能够准确识别用户在对话中表达的真实意图，支持多意图并发识别和意图优先级排序，显著提升对话理解的准确率。

第二，多轮对话模块。多轮对话模块管理对话上下文的完整生命周期，支持跨轮次的上下文追踪、话题切换识别和对话状态管理。通过构建细粒度的对话流编排引擎，鲸智能够处理复杂的多步骤业务查询和引导式服务流程，保障用户在对话中获得连贯、自然的交互体验。

第三，知识库问答模块。该模块将企业内部产品手册、政策文档、常见问题库等非结构化知识整合为可检索的问答资产，结合检索增强生成技术，在对话过程中实时调取相关知识，生成准确、可追溯的答案。知识库问答模块与意图识别模块深度融合，使鲸智在回答专业性问题时能够兼顾流畅对话和事实准确。

第四，坐席协同模块。坐席协同模块支持AI客服与人工坐席之间的无缝转接与协同工作。当AI判断当前问题超出自动化处理范围时，能够将对话上下文完整移交给人工坐席；人工坐席处理过程中，AI实时提供知识推荐和回复建议，辅助坐席提升处理效率和回复质量。

鲸智产品的整体规划由产品负责人陈雨主导，技术研发由首席技术官（CTO）林晓统领。陈雨与林晓共同向CEO周明轩汇报，在产品迭代过程中保持密切协作。

## 核心团队与汇报关系

**周明轩（创始人兼CEO）**是公司最高决策层，统筹公司战略方向、融资规划和核心业务拓展。公司的核心高管团队，包括CTO林晓和产品负责人陈雨，均直接向周明轩汇报。此外，高瓴资本合伙人吴江以董事身份进入蓝鲸科技董事会，代表高瓴资本参与公司重大战略决策，周明轩与吴江在董事会层面保持定期沟通。

**林晓（CTO，技术合伙人）**直接向周明轩汇报，是公司技术战略和研发团队的最高负责人。林晓以技术合伙人的身份加入蓝鲸科技，深度参与公司早期技术路线制定，主导了鲸智四大核心模块的底层架构设计。林晓同时承担公司对外技术合作的代表职能，是蓝鲸科技与清华大学人工智能研究院联合实验室的合作负责人。

**陈雨（产品负责人）**直接向周明轩汇报，全面负责鲸智平台的产品规划、功能路线图制定和客户需求研究。陈雨在企业服务软件产品设计领域具有丰富积累，主导了鲸智从早期MVP到成熟商业化产品的多轮产品演进。陈雨与林晓在日常工作中保持紧密的产品与技术协同。

**吴江（高瓴资本合伙人，董事）**代表高瓴资本出任蓝鲸科技董事会董事。吴江在高瓴资本主导了蓝鲸科技的A轮融资，投后进入董事会参与公司治理，为蓝鲸科技在资源对接、战略建议和行业生态方面提供支持。

## 融资历程

2021年，蓝鲸科技完成A轮融资，本轮融资由高瓴资本领投，融资金额为人民币1亿元，投后估值约为8亿元人民币。高瓴资本是国内头部综合性投资机构，在消费科技、企业服务和医疗健康等多个领域具有深厚的投资积累。高瓴资本以1亿元人民币领投蓝鲸A轮，不仅为公司提供了充裕的扩张资金，也借助高瓴广泛的企业资源为鲸智开拓大型企业客户创造了有利条件。

A轮融资完成后，高瓴资本合伙人吴江正式进入蓝鲸科技董事会担任董事，高瓴的机构背书与行业影响力进一步强化了蓝鲸科技在智能客服赛道的市场地位。

## 清华大学联合实验室

蓝鲸科技与清华大学人工智能研究院合作共建联合实验室，是公司在产学研协同方向的重要战略布局。联合实验室由蓝鲸科技CTO林晓与清华大学人工智能研究院张伟教授共同负责，林晓代表企业侧统筹研究资源和工程落地需求，张伟教授代表学术侧主导前沿算法研究和人才培养。

联合实验室的研究重点聚焦于对话系统中的意图理解、长上下文推理和低资源场景下的知识迁移等前沿课题，研究成果优先应用于鲸智产品的技术迭代。通过与清华大学的深度合作，蓝鲸科技在引进顶尖AI研究人才、获取前沿学术资源方面保持了持续的竞争优势。联合实验室也是林晓主导的对外技术合作体系的核心组成部分，进一步巩固了蓝鲸科技在技术层面的行业影响力。

## 发展里程碑

2020年，蓝鲸科技在杭州正式成立，周明轩带领创始团队启动鲸智产品早期研发，完成产品原型验证。

2021年，鲸智完成核心模块开发并向首批企业客户推出商业化版本；同年，高瓴资本以人民币1亿元领投A轮融资，投后估值约8亿元，高瓴资本合伙人吴江进入董事会担任董事；公司完成与清华大学人工智能研究院的联合实验室共建合作，由林晓与张伟教授共同负责联合实验室运营。

2022年至2023年，鲸智坐席协同模块和知识库问答模块持续迭代升级，在金融、零售和电商等多个垂直行业完成大规模商业落地，累计客户数量显著增长。

2024年，蓝鲸科技员工规模达到约150人，核心业务以鲸智平台的商业化扩张和产品能力纵深为主线，并持续加大对大模型对话能力的研发投入。

## 小结

蓝鲸科技是一家总部位于杭州、专注智能客服与对话AI的科技公司。创始人周明轩主导公司整体战略，林晓以技术合伙人身份负责技术研发并主导产学研合作，陈雨主导鲸智产品规划，二人均向周明轩直接汇报。高瓴资本以1亿元领投A轮并派合伙人吴江进入董事会，提供了强有力的资本背书。蓝鲸科技与清华大学人工智能研究院共建联合实验室，进一步夯实了技术研究基础。以鲸智为核心，蓝鲸科技在智能客服和企业对话AI领域构建起涵盖产品、技术、投资和学术合作的综合竞争优势。
