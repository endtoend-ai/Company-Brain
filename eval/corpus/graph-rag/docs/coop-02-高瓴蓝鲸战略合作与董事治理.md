# 高瓴资本与蓝鲸科技战略投资合作及董事治理

## 投资背景与决策逻辑

蓝鲸科技成立于2020年，总部位于杭州，由CEO周明轩与CTO林晓联合创立，专注于智能客服与对话产品赛道，旗下核心产品鲸智覆盖意图识别、多轮对话、知识库问答与坐席协同等全链路功能。公司成立后，凭借在零售电商、教育等行业的快速商业化，在创立后约18个月内积累了包括米粒电商、星辰教育在内的多个标杆客户，用户留存与收入增长数据均表现突出。

高瓴资本作为专注于科技与消费赛道的头部机构，长期关注企业级AI应用的投资机会。高瓴资本合伙人吴江在内部调研中注意到蓝鲸科技的产品数据后，主动发起了与周明轩的接触。双方在2021年下半年经历了密集的尽职调查与商务谈判，高瓴资本团队对鲸智产品进行了深度的技术验证，并走访了米粒电商等核心客户，对其实际落地效果形成了较高认可。

2022年3月，高瓴资本正式宣布领投蓝鲸科技A轮融资，融资金额为人民币1亿元。本轮融资由高瓴资本单独领投，未引入其他跟投方。这一融资规模在当时的智能客服赛道属于头部水平，充分体现了高瓴资本对蓝鲸科技商业化路径与团队执行力的高度认可。

## 吴江进入蓝鲸董事会

A轮融资协议明确约定，高瓴资本合伙人吴江在本轮融资完成后将进入蓝鲸科技董事会，担任董事一职。这一安排既是高瓴资本作为A轮领投方寻求治理参与的惯例操作，也是周明轩与林晓在融资谈判中主动邀请的结果——创始团队希望借助高瓴资本在企业服务领域的资源网络与产业洞察，为公司下一阶段的战略拓展提供更有力的外部支持。

吴江正式出任蓝鲸科技董事后，每季度参与一次正式董事会，并与CEO周明轩保持月度非正式沟通机制。在董事会层面，吴江主要参与战略规划审议、重大资金使用决策、关键人才引进讨论以及下一轮融资节奏的研判。他并不直接介入产品开发或日常运营，而是作为外部视角的治理参与者，帮助创始团队审视战略选择的合理性与风险敞口。

## 周明轩与吴江的协作模式

周明轩作为蓝鲸科技CEO，在与吴江的协作中逐渐形成了一套成熟的沟通机制。每次董事会前，周明轩会提前两周向吴江提交一份包含业务数据、战略进展与重点议题的简报材料，吴江则在董事会前通过视频沟通就其中的关键问题与周明轩提前对齐，确保正式会议的效率。

在资源对接方面，吴江充分发挥了高瓴资本生态网络的价值。高瓴资本在消费、医疗、教育等行业拥有广泛的被投企业网络，吴江协助蓝鲸科技对接了其中若干有智能客服需求的企业，推动了鲸智在教育赛道的商务拓展，星辰教育即是通过高瓴资本生态渠道引入的客户。与此同时，吴江还协助蓝鲸科技引入了两位具有大型企业服务背景的高级顾问，补充了创始团队在大客户销售与政府关系方面的经验短板。

在人才引进决策上，吴江与周明轩就VP级以上核心岗位的候选人共同讨论，吴江提供来自高瓴投资团队视角的参考意见，最终决策权由周明轩掌握。这种协作模式既保障了创始团队的经营自主性，又充分利用了投资方的外部资源与专业判断。

## 治理结构与资金使用

本轮1亿元A轮融资到账后，蓝鲸科技在吴江参与的董事会讨论中确定了资金使用的三个优先方向：第一，加大鲸智产品的研发投入，重点推进多轮对话与知识库问答的能力升级；第二，扩充企业销售团队，重点突破金融与医疗两个高客单价行业；第三，持续投入与清华大学人工智能研究院联合实验室的合作，以此作为技术差异化竞争力的长期护城河。

董事会同时确定了A轮融资后的关键经营里程碑，包括年度合同额增长目标与核心客户数量目标，这些里程碑将作为B轮融资节奏决策的参考依据。吴江在董事会中对这套目标体系的合理性与可行性表达了认可，并承诺在达成里程碑后积极支持高瓴资本参与B轮融资。

从整体治理效果来看，高瓴资本通过吴江进入蓝鲸董事会的安排，实现了从单纯财务投资向战略型股东的升级，蓝鲸科技也在资金支持之外获得了来自顶级机构的资源赋能与治理背书。这一模式被外界视为蓝鲸科技A轮融资的核心增值要素之一，也为公司后续商务拓展中彰显资本背景提供了重要的信用背书。周明轩在多个公开场合表示，高瓴资本不仅带来了资金，更带来了高瓴体系内的产业资源与市场开拓经验，是蓝鲸科技在A轮阶段最重要的战略合作伙伴。
