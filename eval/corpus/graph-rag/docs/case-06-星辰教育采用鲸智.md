# 星辰教育接入蓝鲸科技鲸智平台：课程咨询智能客服与意图识别精准化实践

## 客户背景

星辰教育是一家总部位于北京的在线教育平台，成立于2015年，主营K12学科辅导、成人职业技能培训和兴趣素质教育三大业务线，注册用户超过三千五百万，年活跃付费学员约四百二十万，课程体系涵盖数百个细分方向，客服场景复杂度高。

## 痛点分析

2022年下半年，用户增长中心负责人林思远通过用户旅程研究归纳了三大智能客服缺陷。其一，原有系统基于关键词匹配，对语义模糊、意图复合的表达识别能力极弱，错误意图判定率约34%，用户体验投诉中约42%与智能客服误导直接相关。其二，系统无法保持多轮对话上下文，用户每次追问需重新描述背景，课程咨询完成率（用户从发起咨询到获得完整课程方案）仅约29%。其三，每年寒暑假报名高峰和大促期间，大量咨询流向人工销售顾问，顾问日均接待量从约八十通增至一百五十通以上，高峰期转化率比平时低约12个百分点。

## 选型与对接

2023年一季度，星辰教育启动智能客服平台升级，经三家产品对比测评，蓝鲸科技旗下鲸智平台在星辰教育提供的五百条真实咨询样本上意图识别准确率达94.1%，最终于2023年4月签约。鲸智由蓝鲸科技成立于2020年的杭州推出，CEO周明轩、产品负责人陈雨和CTO林晓是平台核心建设团队。产品负责人陈雨带队开展三周深度需求访谈，与星辰教育课程运营团队共同完成意图分类体系设计，确定优先部署意图识别引擎和多轮对话模块，知识库问答与坐席协同作为后续阶段扩展。

## 实施过程

项目分三阶段推进，历时约五个月。2023年5月至6月，双方联合完成意图分类框架搭建，针对三大业务线设计差异化意图树结构，共定义一百七十八个意图类目，涵盖课程推荐、价格咨询、试听申请、学习规划等主要场景；基于约九十万条历史对话语料完成定制化模型训练，内部验证集准确率达93.6%。2023年7月至8月，CTO林晓带领技术团队完成多轮对话模块与课程数据库、用户画像系统的集成，支持在对话中动态调取学龄段、历史选课记录和学习目标等个人化信息，三个核心咨询场景支持最多七轮上下文保持；2023年8月完成K12业务线灰度上线。2023年9月，完成职业培训和兴趣素质两条业务线适配，同期对销售顾问完成人机协同工作方式培训，全量上线。

## 量化成效

2023年双十一及年底统计数据显示：意图识别准确率从约66%提升至92.3%，错误引导率下降约64%，智能客服误导类投诉占比从约42%降至约15%；课程咨询完成率从29%提升至54%，大促期间49%的咨询全程由系统完成；人工销售顾问高峰期日均接待量从约一百五十通降至约九十五通，高峰期与平时转化率差距从12个百分点收窄至约4个百分点；平台整体课程咨询转化率在2023年第四季度同比上升约7.2个百分点。

## 后续规划

星辰教育与蓝鲸科技约定于2024年上半年推进知识库问答模块集成，将商品知识库、退费政策等核心内容结构化接入鲸智问答引擎，并于下半年落地坐席协同模块，解决销售顾问实时辅助信息推送需求。
