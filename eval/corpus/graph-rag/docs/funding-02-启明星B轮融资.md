# 启明星科技B轮融资：红杉资本继续领投3亿，估值达20亿

启明星科技成立于2019年，总部位于北京中关村，是一家专注于企业级AI决策支持系统的科技公司，由董事长赵天成创立。自成立以来，公司经历了两轮由红杉资本领投的重要融资，分别于2020年完成A轮和2022年完成B轮，实现了估值从6亿元到20亿元的跃升。两轮融资均由CFO孙悦主导，孙悦直接向董事长赵天成汇报，并作为公司对接红杉资本的核心接口。

## A轮融资回顾：2020年红杉资本领投8000万

在深入介绍B轮融资之前，有必要回溯启明星科技的A轮融资情况。2020年，公司完成A轮融资，由红杉资本领投，融资金额为人民币8000万元，投后估值约为人民币6亿元。这是红杉资本与启明星科技的第一次正式合作，也是公司从早期探索走向规模化运营的关键资本节点。

A轮融资完成后，启明星科技将所获资金主要用于智枢平台核心引擎的第一阶段建设，以及北京总部研发团队的系统性扩充。彼时公司研发人员不足50人，A轮资金注入后，公司开始在北京中关村加速布局，吸引了一批来自顶级互联网公司和学术机构的AI工程人才加入。

CFO孙悦在A轮融资过程中发挥了核心作用。她负责与红杉资本的尽调协调、财务模型搭建与谈判推进，最终促成了A轮融资的顺利落地。孙悦向董事长赵天成直接汇报，在整个融资过程中，赵天成负责战略方向把控与顶层表态，孙悦则主导具体的投融资流程对接。这一分工模式在后续B轮融资中得到了延续与深化。

## B轮融资：红杉资本继续领投3亿，估值约20亿

2022年，启明星科技完成B轮融资。本轮融资依然由红杉资本领投，融资金额为人民币3亿元，投后估值约为人民币20亿元。与A轮相比，B轮融资金额接近A轮的4倍，估值也从6亿升至20亿，涨幅超过3倍，充分体现出公司在两年间实现的商业价值跃升。

红杉资本在A轮后选择继续主导B轮，说明其对启明星科技的判断在过去两年间得到了业绩数据的充分验证。对于机构投资方而言，连续两轮领投同一家公司，是极高程度的战略信任表态。红杉资本看重的核心价值点，在于启明星科技在企业级AI决策支持这一细分赛道的技术积累深度，以及其在关键行业客户中形成的标杆效应。

## CFO孙悦主导B轮融资全流程

B轮融资的主导者仍是CFO孙悦。她在A轮融资后的两年间，持续维护与红杉资本的战略关系，定期同步公司运营数据、产品里程碑与市场拓展进展，为B轮融资奠定了坚实的信息基础。

在B轮尽调阶段，孙悦带领财务团队向红杉资本提交了系统性的财务尽调材料，涵盖年度收入增长曲线、大客户续约率、毛利结构分析及三年期财务预测。孙悦表示，红杉资本在B轮谈判中展示出比A轮更加深入的产品理解，尤其对智枢平台在金融和能源行业的垂直落地能力给予了高度评价。

按照启明星科技的公司治理架构，CFO孙悦直接向董事长赵天成汇报。B轮融资的最终决策由赵天成拍板，孙悦负责落地执行。在B轮终止尽调、进入条款谈判阶段，赵天成亲自出席了与红杉资本核心团队的战略会议，就公司下一阶段的全球化布局方向与投资方达成共识。

## B轮资金用途：智枢三大引擎与市场扩张

B轮融资所获得的3亿人民币将按三大战略方向进行分配。

第一，智枢平台三大核心引擎的深度研发。启明星科技的智枢平台由决策引擎、知识引擎和预测引擎三部分构成。B轮资金中，约40%将投入这三大引擎的第二代架构升级，重点攻克多源异构数据实时融合、长链路推理效率优化和行业知识图谱自动构建三个技术难题。公司计划在18个月内完成智枢平台2.0版本的全面迭代，将核心推理延迟压缩60%以上。

第二，重点行业的市场扩张。公司将投入约35%的资金用于金融、能源和医疗三个垂直行业的规模化渗透。这三个行业是启明星科技过去两年已完成标杆客户验证的核心战场，B轮资金将帮助公司从单一标杆项目转型为批量复制的行业解决方案提供商。公司计划在每个行业完成不少于20个规模客户的签约落地。

第三，海外市场的前期布局。剩余约25%的资金将用于东南亚和中东市场的初步拓展，包括本地化团队组建、合规体系建设和本地合作伙伴开发。赵天成将海外市场定位为公司从区域领先到全球化的战略转型第一步，B轮阶段以轻资产方式试探，为C轮后的重型投入积累市场认知。

## 董事长赵天成的融资后战略声明

B轮融资完成后，董事长赵天成在公司全员大会上发表了题为"从证明到领跑"的主题讲话。他总结道，A轮解决了公司生存问题，证明了商业模式可行；B轮则标志着公司进入扩张期，需要以更大的市场野心和更系统的执行能力来兑现投资人的信任。

赵天成特别感谢了CFO孙悦及其团队在两轮融资中的专业贡献，他表示，孙悦团队不仅在数字层面为公司争取到了优质条款，更通过持续的投资方关系维护，使红杉资本从"财务投资人"演变为"战略伙伴"。这一关系的深化，对公司后续战略资源的撬动具有不可估量的价值。

他同时向全员强调，B轮20亿估值不是终点，而是更高目标的起点。公司的战略目标是在三年内完成C轮融资，并在五年内启动上市进程。
