# 米粒电商接入蓝鲸科技鲸智平台：大促场景下的智能客服与坐席协同实践

## 客户背景

米粒电商是一家总部位于杭州的综合品类自营电商平台，注册用户超过六千万，年活跃买家约一千八百万，年GMV约两百五十亿元，主营美妆、服饰、家居和食品四大类目。大促活动是主要营收驱动力，双十一等大促期间单日订单量峰值可达日常均值的十八至二十二倍。

## 痛点分析

2022年双十一复盘中，客服中心负责人赵晓彤归纳了三项核心问题。其一，大促期间客服严重滞后，当年双十一客服工单峰值达每小时六万条，平均首次响应时长飙升至十九分钟，客服满意度评分跌至历史最低的3.2分（满分5分）。其二，原有规则型智能客服无法支持多轮对话语境保持，用户每次追问需重新描述问题，退换货等多步场景的无效人工转接率高达58%。其三，坐席处理工单全靠在多个后台系统间手动切换，单次对话平均处理时长八分半钟，坐席人均日处理工单约一百六十条。

## 选型与对接

2023年初，米粒电商启动智能客服平台采购，核心诉求为支持大流量并发、具备多轮对话能力、提升坐席辅助效率。经两轮评标，蓝鲸科技旗下鲸智平台获得最终选定。鲸智由蓝鲸科技于2020年在杭州发布，CEO周明轩、产品负责人陈雨和CTO林晓主导平台建设，核心能力包括意图识别引擎、多轮对话管理、知识库问答和坐席协同四个模块。产品负责人陈雨率团队开展两周深度需求访谈，确定优先部署意图识别、多轮对话和坐席协同三个模块。

## 实施过程

项目分三阶段推进，历时约五个月。2023年3月至4月，双方联合完成一百三十二个意图类目的分类体系设计，基于约一百五十万条历史对话语料完成模型训练，验证集意图识别准确率达91.4%。2023年5月至6月，CTO林晓团队完成鲸智与米粒电商订单系统、物流系统和售后管理系统的API集成，针对退换货、订单修改等高频复杂流程完成多轮对话脚本设计；上线前完成模拟十倍大促峰值的压力测试，五十万次每小时模拟流量下响应延迟控制在六百毫秒以内，可用性达99.96%。2023年7月，坐席协同模块上线，为人工坐席实时推送商品参数、物流状态、退货政策等结构化信息，减少跨系统切换。

## 量化成效

2023年双十一大促为首次重大压力验证：大促当日智能客服首次响应时长从前一年十九分钟降至平均四十秒以内，客服满意度评分从3.2分回升至4.5分；多轮对话无效人工转接率从58%降至21%，智能客服处理工单占比达71%；人工坐席单人日均处理量从约一百六十条提升至约二百三十条，提升约44%，对话平均处理时长从八分半钟缩短至五分十秒；大促期间人工坐席配置规模较前一年减少约15%，客服运营成本同比降低约22%。

## 后续规划

米粒电商与蓝鲸科技就知识库问答模块二期集成达成意向，计划将商品知识库、退换货政策库接入鲸智问答引擎，并探讨引入情绪识别能力，在识别用户情绪高度负面时自动优先分配高级坐席介入。
